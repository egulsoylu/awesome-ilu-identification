About the data

The review follows PRISMA-ScR. Studies were found in Google Scholar, dblp and OpenAlex (cut-off 12 October 2026), screened, and charted on one set of data items. Each coded value is backed by whole-sentence quotes from the study, shown under Evidence in a study's record. Not reported means the study is silent on the item.

The coding rule of every column (what counts as end-to-end accuracy, as an image, as a camera position, …) is given in Supplementary Section S1 of the review. Corrections are welcome as GitHub issues.
